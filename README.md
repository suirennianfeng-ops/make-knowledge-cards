# make-knowledge-cards

一个 Claude Code Skill:把用户粘贴的文章或本地 Markdown/TXT 文件,自动转换成 5~8 张结构化的知识卡片,便于复习与自测。

## 项目解决什么问题

读完一篇长文章后,真正重要的知识点往往散落在全文各处,复习时难以快速定位,自测时更无从下手;手动整理卡片又费时费力。

make-knowledge-cards 解决的就是这个问题:把一篇文章自动提炼成一张卡片一个知识点的卡片组,每张卡片都包含"必须记住的一句话 + 简明解释 + 例子或自测题",让你可以直接用来回顾、背诵和检验理解。适合备考复习、阅读笔记、学习新领域等场景。

## 主要功能

- **两种输入方式**:直接粘贴文章文本,或提供本地 `.md` / `.txt` 文件路径
- **结构化输出**:每张卡片包含标题、核心知识(一句话)、简明解释(2~4 句)、例子或自测问题
- **只提取真正重要的知识**:跳过铺垫、寒暄、重复论述和无关细节;一张卡片只讲一个知识点
- **自动去重**:表达不同但意思相同的知识点合并为一张卡片
- **忠于原文**:不编造原文没有的信息,例子优先取自原文,自测题只考察卡片已有内容
- **数量弹性**:目标 5~8 张;原文信息不足时不硬凑数量,信息过多时按重要性取舍
- **可选保存**:默认在对话中输出,也可按用户要求保存为 `.md` 文件

## 安装方法

1. 将整个 `make-knowledge-cards` 文件夹复制到以下任一位置:

   | 范围 | 路径 |
   | --- | --- |
   | 个人技能(全局可用) | `~/.claude/skills/make-knowledge-cards/`<br>Windows 示例:`C:\Users\<用户名>\.claude\skills\make-knowledge-cards\` |
   | 项目技能(仅当前项目) | `<项目根目录>/.claude/skills/make-knowledge-cards/` |

2. 重启 Claude Code(或新开一个会话)生效。
3. 生效后,粘贴文章并说"转成知识卡片"即可触发,无需其他配置。

## 使用方法

**方式一:粘贴文章**

把文章全文粘贴到对话中,附上"转成知识卡片""做成知识卡片"等说明即可:

```
把下面这篇文章做成知识卡片:

<粘贴文章全文>
```

**方式二:本地文件**

直接给出 `.md` 或 `.txt` 文件路径:

```
把 D:\docs\article.md 做成知识卡片
```

**方式三:保存结果**

默认在对话中直接输出卡片;需要保存时指定路径:

```
把 ./notes/reading.md 做成知识卡片,保存到 ./cards.md
```

只要求保存但未指定文件名时,会以 `知识卡片-<文章主题>.md`(无法概括主题时为 `knowledge-cards.md`)写入当前目录。

## 输入输出示例

**输入**(短文示例):

```
二八定律,也叫帕累托法则,是指约 80% 的结果来自约 20% 的原因。
它最早由意大利经济学家帕累托在观察财富分配时提出:当时约 20%
的人口拥有约 80% 的财富。这个规律后来被推广到很多领域,比如
约 20% 的客户贡献约 80% 的收入,约 20% 的代码产生约 80% 的问题。
二八定律的价值不在于精确的数字,而在于提醒我们把注意力集中在
少数真正重要的因素上:找出那 20% 的高价值工作并优先完成,效率
会远高于平均用力。需要注意的是,20% 和 80% 只是一个约数,不同
场景下比例会变化,不能机械套用。
```

**输出**(4 张卡片;原文信息量不足 5 个知识点,按"不硬凑"原则不强行凑足):

```markdown
### 卡片 1:二八定律的定义与起源

**核心知识**:二八定律(帕累托法则)指约 80% 的结果来自约 20% 的原因。

**简明解释**:该定律由意大利经济学家帕累托提出,最初来自他对财富分配的观察:约 20% 的人口拥有约 80% 的财富。

**例子 / 自测**:自测:二八定律最早观察自哪个领域的什么现象?(答案:财富分配——约 20% 的人口拥有约 80% 的财富。)

### 卡片 2:二八定律的常见应用

**核心知识**:二八定律已被推广到很多领域,如约 20% 的客户贡献约 80% 的收入、约 20% 的代码产生约 80% 的问题。

**简明解释**:80/20 的分布模式在不同领域反复出现,说明"少数关键因素决定大部分结果"是普遍现象。

**例子 / 自测**:例子(取自原文):约 20% 的客户贡献约 80% 的收入。

### 卡片 3:二八定律的价值

**核心知识**:二八定律的价值不在精确数字,而在于提醒我们把注意力集中在少数真正重要的因素上。

**简明解释**:找出那 20% 的高价值工作并优先完成,效率会远高于平均用力。

**例子 / 自测**:自测:按二八定律安排工作,应该优先做什么?(答案:找出少数高价值工作并优先完成,而不是平均用力。)

### 卡片 4:使用二八定律的注意事项

**核心知识**:20% 和 80% 只是约数,不同场景下比例会变化,不能机械套用。

**简明解释**:二八定律描述的是大致的分布规律,并非精确的数学公式,应用时需要结合具体场景判断。

**例子 / 自测**:自测:某团队发现"10% 的客户贡献 70% 的收入",这是否违背二八定律?(答案:不违背——比例是约数,不同场景会变化。)
```

完整的 6 张卡片示例见 [examples/sample-output.md](examples/sample-output.md)。
